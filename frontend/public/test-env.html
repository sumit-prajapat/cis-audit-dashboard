🔍 Environment Variable Diagnostic

⚠️ Note

This is a static HTML file. It cannot access Vite's import.meta.env variables.

To test if environment variables are working, check the browser console on the main app pages (login/register).

📋 What to Check

  1. Open: https://cis-audit-dashboard.vercel.app/register
  2. Press F12 to open DevTools
  3. Go to Console tab
  4. Look for one of these messages:

✅ If Environment Variable is SET:

You should NOT see any warnings about VITE_API_URL

❌ If Environment Variable is NOT SET:

You should see: ⚠️ VITE_API_URL is not set. API requests may fail.
